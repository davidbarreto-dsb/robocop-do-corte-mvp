# 🤖 Robocop do Corte

**Aplicativo mobile para gerenciamento de agendamentos de uma barbearia.**

## 📌 Sobre o projeto

O **Robocop do Corte** é um projeto acadêmico que tem como objetivo desenvolver um aplicativo mobile para facilitar o gerenciamento de agendamentos da Barbearia Robocop do Corte.

A proposta surgiu a partir da identificação de dificuldades na organização dos horários realizados por WhatsApp e ligações telefônicas, como reservas duplicadas, agendamentos em datas incorretas e falta de histórico dos clientes.

A solução busca centralizar essas informações em um único aplicativo, tornando o processo mais simples e organizado para clientes e proprietário.

## 🎯 Objetivos

- Facilitar o agendamento de serviços.
- Permitir a consulta de serviços, preços e horários disponíveis.
- Reduzir conflitos e duplicidade de agendamentos.
- Melhorar o controle dos clientes e dos atendimentos.
- Simplificar a administração da barbearia.

## ✨ Funcionalidades previstas para o MVP

**Área do cliente**
- Cadastro de clientes.
- Consulta de serviços, preços e duração.
- Visualização de horários disponíveis.
- Realização de agendamentos.
- Consulta dos próprios agendamentos.

**Área do proprietário**
- Visualização e gerenciamento dos agendamentos.
- Controle de clientes.
- Gerenciamento de serviços e preços.
- Atualização do status dos atendimentos.

## 🛠️ Tecnologias

- **Flutter:** desenvolvimento do aplicativo mobile.
- **Dart:** linguagem de programação.
- **Supabase:** integração e gerenciamento dos dados.
- **Supabase Auth:** autenticação dos usuários.
- **PostgreSQL:** banco de dados relacional.

## 🏗️ Arquitetura

O projeto utiliza como proposta uma arquitetura monolítica em camadas, organizada em:

1. **Apresentação:** telas e interação com os usuários.
2. **Regras de negócio:** validações e controle dos agendamentos.
3. **Acesso aos dados:** comunicação com o banco de dados.
